# 仕様

最終更新: 2026-10-09

このアプリの振る舞いを定める文書です。コードと食い違ったときは、どちらが正しいかを確認してから直します。決定の経緯は [decision-log.md](decision-log.md) にあります。

アプリ名は仮に **Yoyu(余裕)** としています。商標は未調査です。

## 1. 何のためのアプリか

**後回しにしてきた大事なことを、スマホが止まる前に終わらせるアプリ**です。

対象は、時間がゲームやショート動画に流れてしまう人です。次のような状態を想定しています。

- 締切が今日か明日のものはやるが、締切の遠いもの(院試の勉強、TOEIC など)は永遠に後回しになる
- 締切のあるものも、ぎりぎりまで手を付けない
- 毎日の計画を立てるのは面倒で続かない
- 勉強が嫌いなわけではなく、始めるのが面倒
- 気づくとゲームや動画で1時間たっている

通知は無視できますが、ロックは無視できません。このアプリは、決めたことが終わっていないときに、選んだアプリを開けなくします。

## 2. 用語

| 用語 | 意味 |
|---|---|
| 目標 | 締切が遠い大事なこと。「1日の量(分)」と「やる曜日」を持つ |
| 今日の分 | ある目標について、今日やると決めた量 |
| タスク | 締切のあるやること。「締切」と「所要時間」を持つ |
| 着手リミット | これ以上遅らせると間に合わない時刻。締切 −(所要時間 × 余裕係数) |
| ロック | 選んだアプリ(ゲーム、動画など)が開けない状態 |
| 余裕 | 次のロックが始まるまでの残り時間。このアプリの中心となる数字 |
| 集中 | 目標の今日の分を進めるための時間計測 |
| パス | ロックを一時的に外す非常口。回数に上限がある |
| 1日 | 朝4時から翌朝4時まで(設定で変更できる) |

## 3. ロックの規則

ロックの理由は2種類あります。理由が1つでも残っている間、ロックは続きます。

### 3.1 目標によるロック

- 今日がその目標の「やる曜日」で、今日の分が終わっていなければロックの理由になる
- ロックが始まる時刻は目標ごとに選べる
  - **朝から**(初期値): 1日の開始からロックする
  - **時刻を指定**: その時刻までに終わっていなければロックする
- 集中の合計が今日の分に達したら、その理由は消える
- 今日の分は分割して進めてよい。途中でやめても、やった分は記録に残る

### 3.2 タスクによるロック

- 未完了のタスクは、着手リミットを過ぎた時点でロックの理由になる
- 完了にするか、取り下げるまで続く。締切を過ぎても同じ
- 完了は自己申告で、確認を1回挟む
- 余裕係数の初期値は 1.0(所要時間ちょうど)。設定で 1.25 / 1.5 に上げられる

### 3.3 ロックが外れたあと

- 理由がすべて消えたら、その日は自由に使える
- 新しい理由(別のタスクの着手リミットなど)が来たら、またロックされる

### 3.4 パス(非常口)

- 1回につき15分、ロックが外れる
- 1週間(月曜始まり)に使える回数の初期値は2回。設定で0〜5回
- 使うときは、ボタンを3秒押し続ける。うっかり使わせないため
- 使った回数は振り返りに表示する

### 3.5 抜け道と、その扱い

| 抜け道 | 現在の扱い |
|---|---|
| 完了ボタンを押すだけで外れる | 確認を挟むのみ。使ってみてから対策を考える |
| 目標の量を0にして外す | 未対応。「変更は翌日から有効」にする案がある |
| タスクを取り下げて外す | 取り下げは長押しを要求し、振り返りに回数を出す |
| 設定アプリで権限を切る | 防げない(iOS の仕様) |

## 4. 余裕の表示(このアプリの中心)

ホーム画面の主役は ToDo の一覧ではなく、**次のロックまでの余裕**です。

- ロックされていないとき: 「余裕 2時間14分」と、次に何がロックの理由になるかを出す
- ロック中: 何を終えれば外れるかと、残りの量を出す
- 今日これ以上ロックの予定がないとき: 「今日は自由」と出す
- 今日のロック予定を時刻順に並べた「ロック予報」を出す

余裕を見せる狙いは、ロックされてから動くのではなく、**ロックされる前に片づける**行動を引き出すことです。理想は、一度もロックされない日が続くことです。

同じ情報を、ウィジェットと Live Activity でアプリの外にも出します。

## 5. 画面

| 画面 | 内容 |
|---|---|
| 今日 | 余裕、ロック予報、今日の分、着手リミットが近いタスク |
| 集中 | 全画面の計測。残り時間、目標名、終了時の演出 |
| 予定 | 目標とタスクの一覧、追加、編集 |
| 振り返り | 日ごとの集中時間、ロックを避けた回数、パスと取り下げの回数 |
| 設定 | ロックするアプリ、1日の開始時刻、余裕係数、パスの回数 |
| 初回設定 | 仕組みの説明、最初の目標、ロックするアプリの選択、権限の許可 |

## 6. 演出の方針

ゲームやショート動画に慣れた人が相手なので、地味な管理画面にはしません。

- 力を入れる瞬間: 今日の分を終えたとき、ロックが外れたとき、ロックされる前にタスクを終えたとき
- 使うもの: 動き、振動、色の変化、数字の増減
- 使わないもの: ガチャ的な報酬、連続記録が途切れる不安をあおる表現、罪悪感をあおる文言

このアプリ自体がもう1つの依存先になることは避けます。開いている時間が短いほど良いアプリです。

## 8. 今は入れないもの

- 書籍のバーコード登録
- カレンダー連携、Canvas などの学習管理システムとの連携
- 繰り返しタスク
- クイズや単語カードによる解除
- 複数端末の同期
