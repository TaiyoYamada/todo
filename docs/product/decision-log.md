## 2026-10-09 実装開始時に Claude が決めたこと

| 決定 | 理由 |
|---|---|
| 仮の名前を Yoyu(余裕)とする | 中心となる数字「次のロックまでの余裕」から。短く、英語圏でも発音できる |
| ホームの主役を「余裕」と「ロック予報」にする | 既存のタスク型ブロックアプリは、ロックを今かかっているかどうかでしか見せない。先の見通しを見せれば、ロックされる前に動ける |
| 目標のロック開始は「朝から」を初期値にし、時刻指定も選べる | オーナーは強いロックを希望。ただし朝から使えないと続かない人もいる。目標もタスクも「リミットを過ぎたらロック」という1つの考え方にそろう |
| 完了は自己申告で、確認を1回挟む | 紙の教材では検証できない。まず使ってから対策する |
| パスは15分、週2回まで、3秒の長押し | 逃げ道は必要だが、楽に使えてはいけない |
| タスクの取り下げは長押しを要求し、回数を振り返りに出す | 取り下げが抜け道になるため |
| 1日の区切りは朝4時 | 夜更かしした日の深夜を前日として扱う |
| 余裕係数の初期値は 1.0 | まず単純に。見積もりが甘い人は設定で上げる |
| 連続記録(ストリーク)は作らない | 途切れる不安で縛る手法は、依存を助けるアプリの趣旨に反する |
| ガチャ的な報酬は使わない | 同上 |
| アカウント登録なし、端末内保存のみ | 始めるまでの手間を減らす。個人情報も預からない |

## 壁打ち 第3回(2026-10-09)

技術の面での見直しです。実装とは別の担当に、コードだけを読ませて不具合を探させました。2回行い、あわせて22件の指摘がありました。

### 見つかったことの傾向

| 傾向 | 例 | 対応 |
|---|---|---|
| アプリを閉じている間の、時間だけで起きる変化に弱い | 日付が変わってもロックが外れない。計測が今日の分に達しても外れない | 1日の区切りと、計測が達する時刻に見直しを予約する。実機で確かめる必要がある |
| 1日の区切りをまたぐ計測の扱い | 止めたあと今日の分から消える。前の日の残りで達成と判定する | 区切りで分けて記録し、日付が変わったあとは新しい日の分で判定する |
| 夏時間 | 切り替え日に、1日の開始とロックの時刻が1時間ずれる | 時間の足し引きをやめ、「その日の何時」で求める |
| 1行入力の読み違い | 「9時30分」の30分を所要時間と読む。「明日の中間テスト」の「中」を削る | 読み取りの規則を直し、実例をテストに足した |
| 書き込みが2回に分かれている箇所 | 計測の終了、初回設定の完了 | 1回にまとめるか、途中の状態を見ても誤動作しないようにした |
| 外への連絡の順序 | 古い指示があとから届く | 続けて来たら古いほうをやめ、各段階の前に取り消しを確かめる |

### 判断したこと

- **見つかった不具合は、設計の誤りではなく端の扱いだった。** ロックの判定の中心は、東京の時刻での区切り、週、パスのいずれでも正しかった。設計は変えていない
- **実機でしか確かめられない部分に、指摘が集まった。** スクリーンタイムの予約は、読んで直しただけで動かしていない。公開前の確認事項に、確かめる場面を足した
- **直さなかったもの**: 完了や設定の変更でロックを外せる抜け道。塞ぐかどうかは体験に関わるので、オーナーの判断を待つ

## 見た目の作り直し(2026-10-09)

オーナーが実際の画面を見て、「グラデーションと透かし系の UI は、いかにも AI が良いと思っている見た目だ」と指摘しました。そのとおりで、流れるグラデーション、ガラスのカード、光る数字、丸い小さなラベルは、どれも見栄えのする既定の選択を重ねただけでした。オーナーの好みを聞かずに決めたのが原因です。

オーナーの希望は、**Duolingo のように、単純だが動きが多くて面白い UI** です。

| 決定 | 理由 | 決めた人 |
|---|---|---|
| 質感(グラデーション、ガラス、発光)をやめ、単色で塗る | Duolingo は質感を使わず、動きで楽しく見せている | オーナーの希望を受けて Claude |
| ボタンとカードは、太い枠と、下にずらした縁で厚みを出す。押すと沈む | 影を使わず、形のずれだけで「押せる」感じを出す | Claude |
| 錠前をキャラクターにし、ロックの状態を表情と動きで伝える | 感情をキャラクターに持たせるのが、この種のアプリに共通する型だった | Claude |
| キャラクターのせりふは、くだけた口調にする(「閉めるよ」「おつかれさま」) | キャラクターが丁寧語で話すと、かえって不自然 | Claude。文言はオーナーの確認が要る |
| まず「今日」の画面だけを作り直し、起動引数で切り替えて見比べる | 方向が合っているかを、全体に広げる前に確かめる | オーナーと合意 |

分かっている弱点: Duolingo のキャラクターは、専門のアニメーターが Rive で作っている。このアプリの錠前は、丸と線をコードで描いたもので、絵としての質は及ばない。
