# 事業モデル

調査日: 2026-10-09

## 結論（推奨）

**フリーミアム + 年額サブスク + 買い切り。ロックと「ロック予報」は無料で出し、課金は数量と便利機能に置く。**

| 項目 | 推奨 |
|---|---|
| 無料で使える範囲 | 長期目標 1件、締め切りタスク 同時3件、ロック対象アプリの選択、ロック予報（ホーム・ウィジェット・Live Activity）、緊急パス |
| Pro で解放するもの | 目標・タスクの件数無制限、カレンダーやリマインダーからの取り込み、見積もりの自動補正と統計、緊急パスや厳格モードの細かい設定、iCloud 同期、テーマ |
| 価格（日本） | 月 ¥480 / 年 ¥2,900（7日無料）/ 買い切り ¥6,800 |
| 価格（米国） | 月 $3.99 / 年 $24.99 / 買い切り $59.99 |
| やらないこと | 起動直後の課金必須、緊急パスの追加販売、広告 |

価格は競合の水準から置いた出発点で、検証された最適値ではない。公開後に実測して調整する前提。

## 根拠

### 1. 学生は無料でないと広がらず、広がると課金率は下がる

Opal は課金必須から無料枠ありに切り替え、ダウンロードから課金への転換率が 20% から 9% に下がった一方、高校生・大学生が DAU の3分の2を占めるようになり、DAU 100万超・ARR 1,000万ドルに達したと報じられている（[RevenueCat, 2026-04](https://www.revenuecat.com/blog/growth/kenneth-schlenker-sub-club-podcast-2026)。CEO 発言で未監査）。記事は無料利用者が「マーケティングの原動力」になったと説明している。

対象が学生で、広告費をかけずに利用者を増やしたいなら、同じ構図になる。

転換率の 10.7% と 2.1% は、RevenueCat の資料内で「ダウンロードから課金」と「トライアルから課金」の両方の呼び方がされており、定義に揺れがある。ここでは前者として扱う。

課金必須のほうが転換率は約5倍になる。広告で獲得して回収する運営なら課金必須が合理的で、Unrot、TaskWarden、Proc はこの形を取っている（competitors.md）。今回の目的（学生に広げる、広告費なし）とは合わないので採らない。

年額の1年後継続率が3割弱という点は重い。2年目の売上は初年度の3割程度しか残らない前提で考える必要がある。

### 4. 推奨価格の理由

- **年 ¥2,900**: 日本の競合の下限寄り。無名の新規アプリが学生に払ってもらうには、スタロックの割引価格と同じ帯にいる必要がある。年額は月額の約6か月分にあたり、年額へ誘導する比率にした。
- **買い切り ¥6,800**: 年額の約2.3年分。年額の1年後継続率が3割弱なら、買い切りのほうが1人あたり売上は高くなる。サーバーを持たず端末内で完結させれば、買い切りでも継続費用は増えない。
- **7日無料**: 3日では当日解約が過半になる。長い期間ほど転換率は上がるが、このアプリは「締め切りを1回乗り切る」体験に1週間ほどかかるため7日とした。
- **緊急パスを売らない**: 追加の緊急パスを都度課金にすると、利用者が負けるほど儲かる構造になり、アプリの目的と利害が逆になる。評判面の損が大きいと判断した（意見であり、検証はしていない）。

## App Store ガイドライン上の制約

ガイドライン 4.10 は「OS やハードウェアの組み込み機能、Apple のサービスや技術（例として Screen Time API を明記）を収益化してはならない」と定めている（[App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)）。

- 実態として、Opal をはじめ多数のアプリがブロック機能の一部を有料にして公開されている。この条項が Screen Time 系アプリの課金でどう運用されているかを示す事例は見つけられなかった（未確認）。4.10 での却下事例として確認できたのは、バックグラウンド音声を有料にした配信アプリの1件（[開発者フォーラム](https://developer.apple.com/forums/thread/767043)）。
- 安全側に倒すなら、「ロックできるかどうか」自体を課金の境目にせず、件数・取り込み・統計・同期といったアプリ独自の価値に課金を置く。上の推奨はこの考え方に沿っている。
- 自動更新サブスクは「継続的な価値」の提供が条件（3.1.2(a)、[同ガイドライン](https://developer.apple.com/app-store/review/guidelines/)）。機能追加が止まるなら買い切りのほうが説明しやすい。

## 収支の目安（推測）

仮定: フリーミアムの転換率は RevenueCat の中央値 2.1% と上位4分の1の 4.5%。課金者は全員が年額 ¥2,900 を選ぶ。Apple の手数料は Small Business Program の 15%（[Apple](https://developer.apple.com/app-store/small-business-program/)）。2年目以降の継続、買い切り、為替、税は考慮しない。

| 累計ダウンロード | 転換 2.1% の課金者 | 手取り（年） | 転換 4.5% の課金者 | 手取り（年） |
|---|---|---|---|---|
| 1万 | 210人 | 約52万円 | 450人 | 約111万円 |
| 5万 | 1,050人 | 約259万円 | 2,250人 | 約555万円 |
| 20万 | 4,200人 | 約1,035万円 | 9,000人 | 約2,220万円 |

個人開発の副収入を超えるには、累計5万ダウンロード以上が目安になる。market-and-demand.md の推測では日本の学生だけで見込めるアクティブ利用者は1〜2万人規模なので、日本の学生だけを相手にした場合の売上は大きくならない。英語圏への展開と、社会人の資格学習層（支払い能力がある）への拡張が、事業として成立させる条件になる。
